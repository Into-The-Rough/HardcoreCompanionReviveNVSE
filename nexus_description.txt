[size=4][b]Hardcore Companion Revive[/b][/size]

In vanilla hardcore mode, companions go down and either get back up on their own or die permanently with no way to intervene. This mod gives you that option.

When a companion is knocked unconscious in hardcore mode, activate them to revive them using a stimpak (or scrap metal for robots). They get back up with 25% health instead of full, so reviving mid-combat is a tactical decision, not a free reset.

[size=3][b]Features[/b][/size]
[list]
[*]Activate downed companions to revive them with a stimpak (humans) or scrap metal (robots)
[*]Companions revive at 25% health
[*]Custom "Revive" activation prompt when looking at a downed companion
[*]On-screen markers showing where downed companions are (requires [url=https://www.nexusmods.com/newvegas/mods/66901]JVO[/url] or [url=https://www.nexusmods.com/newvegas/mods/66666]JAM[/url])
[*]Optional bleedout timer - companions die permanently if not revived in time
[*]Optional combat revive restriction
[*]All features configurable via INI
[*]Only active in hardcore mode
[/list]

[size=3][b]Configuration[/b][/size]

Edit [font=Courier New]Data\config\HardcoreCompanionReviveNVSE.ini[/font]:

[code]
[General]
bShowMessage=1      ; show UI notifications
bShowIcon=1         ; show downed companion markers (needs JVO/JAM)
bAllowInCombat=1    ; allow reviving during combat
bAllowDeath=1       ; enable bleedout death timer
fBleedoutTime=4.0   ; hours before a downed companion dies (if bAllowDeath=1)
[/code]

[size=3][b]Compatibility[/b][/size]

[b]Stewie Tweaks[/b]
This mod conflicts with several [url=https://www.nexusmods.com/newvegas/mods/66347]Stewie Tweaks[/url] settings that patch the same addresses. If using both, disable the following in Stewie's INI:

[list]
[*][b]bReviveUnconsciousCompanions[/b] - conflicts with this mod's revive and activation hooks. Disable it entirely.
[*][b]fUnconsciousTime[/b] (under Revive Unconscious Companions) - conflicts with this mod's unconscious timer handling.
[*][b]bReviveWhenChangingCells[/b] (under Revive Unconscious Companions) - conflicts with this mod's life-state hooks.
[*][b]bEssentialCompanions[/b] (under Hardcore Tweaks, when bHardcoreTweaks=1) - conflicts with this mod's essential companion patch.
[/list]

Recommended Stewie config: Disable [b]bReviveUnconsciousCompanions[/b] and disable [b]bEssentialCompanions[/b].

[b][url=https://www.nexusmods.com/newvegas/mods/66901]JVO - Just Visual Objectives[/url] / [url=https://www.nexusmods.com/newvegas/mods/66666]JAM - Just Assorted Mods[/url][/b]
Downed companion markers use JVO's HUD framework. Without JVO or JAM installed, everything works except the on-screen markers.

[b][url=https://www.nexusmods.com/newvegas/mods/92538]Stim Your Friends[/url][/b]
No conflicts. Stim Your Friends handles healing standing companions via companion wheel/hotkey. This mod handles reviving downed companions via direct activation. Different input paths, different companion states.

[b][url=https://www.nexusmods.com/newvegas/mods/64857]FO4 Style Companion Reviving[/url][/b]
Does the same thing. Use one or the other.
